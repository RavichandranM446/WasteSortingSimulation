# Waste Sorting Simulator (Unity Educational Simulation)

Waste Sorting Simulator is an educational simulation developed using Unity. It helps users understand proper waste management by allowing them to sort waste into correct categories.

## ♻️ Features

- Interactive waste sorting system
- Multiple waste categories
- Real-time user interaction
- Educational simulation environment
- Object detection and sorting logic

## 🛠️ Built With

- Unity Engine
- C#
- Visual Studio Community

## 🎯 Purpose

This project was created to demonstrate:

- Educational simulation development
- Interactive object handling
- Game logic implementation
- Environmental awareness concepts

## 📁 Project Structure

- Assets → Scripts, prefabs, scenes
- Packages → Unity packages
- ProjectSettings → Unity configuration

## ▶️ How to Run

1. Open Unity Hub
2. Open this project
3. Load main scene
4. Click Play
